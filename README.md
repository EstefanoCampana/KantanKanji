## Welcome to KantanKanji!

Your guidance through your first steps on learning japanese!

## What is there to discover?

With KantanKanji, you can learn the basics of how to read, speak, write and listen japanese at a intermediate level! Learn new words everyday, practice kana and kanji reading, use particles in real-life examples! Stuff you are not going to find in Duolingo of course!

## Purpose

This is a project made for learners by learners, any suggestion is very welcomed, as my intention for doing this is mainly because I also need an application I can use to keep on practicing the concepts that are harder in real life.
